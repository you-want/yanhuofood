# 🔥 今天吃什么？我用 AI 做了一个管一周菜单的工具

> #VibeLaunch 沸点秀# | 烟火食间：把口味、忌口、健康目标变成可执行的周菜单 + 采购清单

## 痛点

"今天吃什么"只是开头。真正麻烦的是同时考虑：

- 家人口味和忌口
- 这周预算多少、有几分钟做饭
- 上次吃过什么、营养够不够均衡

靠脑子记太累，所以我做了 **烟火食间**。

🌐 在线体验：https://www.yanhuofood.com
💻 GitHub：https://github.com/you-want/yanhuofood

## 它做了什么

```
饮食偏好 -> AI 菜单 -> 菜品做法 -> 食材汇总 -> 采购清单
```

**生成前**：选菜系、忌口、健康目标、人数、餐次、预算、烹饪时间。菜单不是随便推荐几道，而是带着约束条件生成的。

**生成后**：完整周菜单 + 营养概览，支持换菜、整餐替换、查看详情。

**最实用的一点**：自动把所有菜品食材汇总成采购清单，标记"待买 / 已买 / 家有"，去超市直接照着走。

## 技术栈（简要）

- 前端：静态站
- AI：大模型 API 生成菜单和食谱
- 浏览器端支持自定义模型配置，数据仅存本地
