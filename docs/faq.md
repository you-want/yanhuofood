# 常见问题

## 烟火食间是开源项目吗？

目前不是。这个仓库是公开的产品与社区仓库，应用源码仍然保存在私有仓库中。

## 为什么建立公开 GitHub 仓库？

我们希望让产品路线图、更新记录和问题反馈更加透明，也让关注产品的人可以通过 Star 表达支持并持续关注进展。

## 未来会开源吗？

我们会评估开放部分通用模块、数据格式或工具组件的可能性，但目前没有完整开源的时间表。

## 可以提交 Pull Request 吗？

可以提交公开文档、FAQ、链接和社区说明相关的修正。当前不接收应用源码贡献。

## 如何体验产品？

访问 https://www.yanhuofood.com 。

## 模型配置会上传吗？

用户在产品中配置的本浏览器模型信息仅保存在当前浏览器。不要在 Issue 或截图中公开 API Key、访问令牌或完整模型配置。

## AI 生成的菜单可以替代医生或营养师吗？

不能。产品提供的是辅助规划和估算，不构成医疗诊断或专业营养建议。涉及疾病、过敏、孕期、儿童或老年人等特殊情况时，应咨询医生或注册营养师。

## 如何反馈 Bug 或建议？

使用 GitHub 的 [Issue 模板](https://github.com/you-want/yanhuofood/issues/new/choose)。提交前请移除个人信息和敏感凭据。
