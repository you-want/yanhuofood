## 8. 真实 Key 联调记录（2026-07-22）

### 联调结论

- 地址解析、周边餐饮搜索、GPS 坐标转换、第二页加载均已通过真实高德 Key 验证。
- 北京中关村软件园、上海张江高科技园区、深圳腾讯滨海大厦三个办公区均能返回足量真实餐饮 POI。
- 高德评分数据在本次样本中覆盖较完整；人均价格和营业时间在不同城市存在明显缺失差异。
- `openStatus` 继续保持 `unknown`：营业时间文本不等于可靠的实时营业状态，产品不得把它包装为“当前一定营业”。
- 是否支持外卖、配送费、配送范围、起送价和送达时间仍需用户前往外卖平台确认。

### 联调中发现并修复的问题

- 高德 WebService v5 周边搜索响应中的 `count` 表示本次请求实际返回数量，不是所有分页的总数量。
- 原实现把 `count` 当总数，第一页返回 20 条时会错误隐藏“加载更多”。
- 现改为 API 返回 `hasMore`：当上游返回满页且尚未达到单次检索 200 条上限时允许继续加载；当返回不足一页时停止。
- 已增加 Provider 分页边界测试，以及桌面端和移动端的“加载更多”回归测试。
